# 记忆法：页面里每一块为什么这么设计

页面不是「台词阅读器」，是一套有顺序的记忆流程。顺序不能颠倒。

## 第 1 步 · 骨架（先记画面，不记词）

把整篇压成 6-10 个画面。背的时候只记「现在第几拍、画面是什么」，词自己会跟着画面流出来。

- 话剧：按冲突/包袱分段（背小抄 → 机械问好 → 指错路 → 被抓住 → 反转 → 点题 → 收尾 → 升华）
- 演讲：按论证单元分段（开场钩子 → 提出问题 → 我的立场 → 证据 → 反方 → 收束）

数量控制在 6-10。少于 6 说明拆得不够细，忘一句就整段崩；多于 10 说明太碎，背骨架本身就成了负担。

**页面上**：② 骨架速记卡片，点任意一张直接跳到该段第一句。

## 第 2 步 · 锚点（只记每句的头两三个词）

长句记不住是因为在背「一整句」，而人脑接话靠的是「开头」。只记开头两三个词，中间部分靠嘴的惯性接上去。

- 锚点要选**结构词**，不要选实义词：`Dear freshmen —`、`But here is the truth:`、`Not at all!` 比 `English`、`problem` 好用
- 页面上 ⚙️ 的 `anchorWords` 控制露几个词，默认 2；台词短、虚词多时调到 3

**页面上**：④ 锚点训练区只列你要背的句子，红色加粗是锚点，其余先遮住。能在心里接上就算过。

## 第 3 步 · 零件（背一句白送两三句）

话剧和口语演讲都有大量重复句式。把这些句式拎出来单练，性价比最高。

写进 `keyParts`，例如：

```
and you? ×2
go straight / turn left ×3
cheat sheet ×4
grammar / accent / mistakes 三连 ×2
```

**页面上**：帮助卡和「复制使用说明」里会带上这一段，发到剧组群，全员受益。

## 第 4 步 · 道具小抄（合法提词器）

`cheatWords` 决定抄几个词，默认 3。抄到实物纸张上。

有意思的是：如果剧本本身就写了「小抄」这个道具（比如《Brave to Speak》），提词天然不穿帮——抄小抄就是剧情。这是可以主动利用的。

**页面上**：📝 生成我的台词小抄 → 每句 `序号. [段名] 角色：头三个词 …` → 复制到备忘录或抄纸上。

## 第 5 步 · 跟读（把节奏录进耳朵）

对词录一遍，走路睡前循环听。语速用页面默认的 `rate = 0.95`，比正常稍慢，方便跟。

**页面上**：① 声音设置里每个角色可单独选音色，按角色分配不同音色，耳朵能靠音色分辨轮到谁。

## 第 6 步 · 忘词保命（现场兜底）

写进 `rescueLines` 的三条。原则：**宁可把话头递给对手，也不要在台上空白**。

- 自嘲拖时间：`"My brain is sweating!"`
- 否定重启：`"No, no, no! Wrong line!"`
- 递话给对手：让对方接 `"Wait — what are you hiding?"`

**页面上**：帮助卡与复制文本里带上，排练时就练一次，真用得上。

## 排练节奏（默认四天）

| 天 | 做什么 |
|---|---|
| D1 | 通读全场 3 遍 + 录音。不背，只求顺 |
| D2 | 分拍背。用「只看我」模式逐拍过，卡住就看锚点 |
| D3 | 合词对练。磨包袱点的停顿节奏（这天的重点是停顿，不是词） |
| D4 | 带动作走全场 2 遍 + 录像回看 |

时间紧就压成两天：D1 = D1+D2，D2 = D3+D4。但要保住「带动作走全场」这一步——动作是记忆的第二条线索，跳过它等于扔掉一半的提示。

## 页面交互与这套方法怎么配合

| 交互 | 对应哪一步 |
|---|---|
| 绿色 = 我的词 / 橙色 = 对方的词 | ③ 顺序练习：对方的自动播放，轮到你就停下等你脱稿，模拟真实接话 |
| 「💡 看锚点」只露前几个词 | 第 2 步，强制从锚点起句，不许整句念 |
| 「🔁 循环本句」 | 第 5 步，一句听到能跟上为止 |
| 「👁 显示全文」 | 兜底，实在接不上才用，用多了等于没练 |
| 「只看我 / 只看对方」跳句 | D2 分拍背时逐句过 |
| 进度自动保存 | 换设备/刷新不丢，排练可断点续 |
